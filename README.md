
# 🐧 Flappy Penguin — Arctic Adventure

A fun, interactive browser-based arcade game featuring a flying penguin, icy obstacles, animated snow, score tracking, and a responsive Arctic environment.

## Overview

Flappy Penguin is a JavaScript-powered arcade game inspired by classic side-scrolling obstacle games. Players control Pip the penguin and navigate through icy pillars while trying to achieve the highest possible score.

## Features

- Interactive penguin character with animated wings
- Gravity-based movement and jumping mechanics
- Randomly generated ice obstacles
- Collision detection
- Real-time score tracking
- Persistent best score using localStorage
- Sound effects with mute control
- Animated snow particles
- Game-over and restart functionality
- Keyboard, mouse, and touchscreen controls
- Responsive interface

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- HTML Canvas API
- Web Audio API
- Browser Local Storage

## How to Run

1. Clone this repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` in your browser.

You can also use the VS Code Live Server extension.

## Controls

| Control | Action |
|---|---|
| Space | Flap |
| Arrow Up | Flap |
| Mouse Click | Flap |
| Touch | Flap |

## Game Objective

Help Pip fly through the ice pillars without colliding with them.

Every successfully passed obstacle increases your score. Try to beat your personal best!

## Technical Highlights

- Canvas-based rendering
- Animation loop using requestAnimationFrame
- Delta-time movement updates
- Random obstacle generation
- Rectangle-based collision detection
- Local storage for persistent scores
- Procedural sound effects
